# quantum-self-consistent-field
A GPU-accelerated Hartree–Fock solver for the 2D H2 molecule, implemented from scratch with CuPy and FFT-based methods.

Solving the 2D Time Independent Schrodinger's Equation for a damped two-proton potential

The goal of this project is not to compete with established quantum
chemistry software, but to understand how the Hartree–Fock equations
can be used to acquire solutions to the schrodinger's equation whose 
analytical solutions dont exist.

# Overview
The solver represents molecular orbitals directly on a 2D real-space grid
and solves the self-consistent field problem using imaginary-time
propagation.


It currently implements:

- 2D real-space wavefunctions
- Imaginary-time propagation
- FFT-based kinetic-energy propagation
- FFT-based Hartree potential evaluation
- Self-consistent Hartree–Fock iterations
- Symmetry-related spin densities for H₂
- GPU acceleration using CuPy
- H2 potential-energy / bonding curves
- Electron-density visualization

## The physics

For two electrons in the H₂ molecule, the calculation contains

    kinetic energy
    electron–nuclear attraction
    electron–electron repulsion
    nuclear–nuclear repulsion

The total energy is evaluated as

    E = T + E_ne + E_ee + E_nn

where the electron–electron term is obtained from the Hartree potential
generated by the electron density.

The electronic orbitals are obtained self-consistently:

    density
       ↓
    Hartree potential
       ↓
    effective Hamiltonian
       ↓
    imaginary-time propagation
       ↓
    new orbital
       ↓
    new density
       ↓
     repeat

## Numerical method

The spatial domain is discretized on a uniform Cartesian grid.

The kinetic operator is applied in Fourier space:

    exp(-Δτ T)

while the potential operator is applied in real space:

    exp(-Δτ V / 2)

using a split-operator imaginary-time propagator.

The Hartree potential is calculated using an FFT-based convolution with
the Coulomb Green's function.
